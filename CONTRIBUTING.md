# Contributing to AgriNexa 🌾

Thank you for your interest in contributing to **AgriNexa** — the 100% Free & Open-Source Farm Financial Management & Voice AI App built for Indian producers, crop growers, and dairy farmers.

---

## 🚀 How You Can Help

We welcome contributions from developers, agronomists, translators, and UI designers! Here are some key areas where you can contribute:

1. **🌐 Language Translations**:
   - Add new regional language translations in `src/data/translations.ts` (e.g., **Kannada, Tamil, Marathi, Punjabi, Gujarati, Bengali, Odia**).
2. **🎙️ Voice AI Engine**:
   - Improve voice command pattern matching and Web Speech API accuracy for agricultural dialects.
3. **📷 Camera OCR & Bill Recognition**:
   - Enhance client-side image processing for paper bills from rural fertilizer & seed stores.
4. **📊 Agronomic Math Models**:
   - Expand cost-per-acre and break-even calculators for specialized crops (Spices, Horticulture, Poultry, Aquaculture).

---

## 🛠️ Development Setup

```bash
# 1. Clone the repository
git clone https://github.com/your-username/agrinexa.git

# 2. Navigate to directory
cd agrinexa

# 3. Install dependencies
npm install

# 4. Start local dev server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

---

## 📋 Pull Request Guidelines

1. **Create a Feature Branch**: `git checkout -b feature/add-kannada-support`
2. **Commit Changes**: Keep commit messages clear and descriptive.
3. **Verify Build**: Ensure `npm run build` runs cleanly with 0 TypeScript compilation errors before submitting PR.
4. **Submit PR**: Open a Pull Request on GitHub with a summary of changes!

---
